# АЛМАНАХ ⚡

**Real-time multiplayer quiz battles in Bulgarian** — duels, an 8-player Royale with eliminations, a daily challenge,
challenge links for friends, and private rooms. Play at **[almanac.bg](https://almanac.bg)**.

The game is open source: **[almanac-bg/almanac](https://github.com/almanac-bg/almanac)** (React, Node.js,
Socket.IO, SQLite · AGPL-3.0). Bug reports, ideas and pull requests are welcome — see its
[contributing guide](https://github.com/almanac-bg/almanac/blob/main/CONTRIBUTING.md). Questions for the game are
submitted in the game itself.
