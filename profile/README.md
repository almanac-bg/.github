# АЛМАНАХ ⚡

**Куиз битки в реално време, на български**: дуели, Роял за 8 играчи с елиминации, дневно предизвикателство,
предизвикателства към приятели с линк и частни стаи. Играй на **[almanac.bg](https://almanac.bg)**.

Играта е с отворен код: **[almanac-bg/almanac](https://github.com/almanac-bg/almanac)** (React, Node.js,
Socket.IO, SQLite · AGPL-3.0). Сигнали за грешки, идеи и pull request-и са добре дошли — виж
[как да помогнеш](https://github.com/almanac-bg/almanac/blob/main/CONTRIBUTING.md). Въпроси за играта се
предлагат направо в нея.
